What is the difference between an ID and a class?

An ID should be unique on a page. After an ID is used, it should not be used anywhere else. We can repeat classes all we want.

What is the difference between a SPAN TAG and DIV tag?

The SPAN tag can select text and you can add a class to the text. The DIV tag causes line breaks before and after all line breaks.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

There is no difference. They act all the same.
