Why do we need a viewport meta tag?

It tells the phone's browser to use the device's real screen insteaed of shrinking a desktop-sized page down to fit.

Which flex-direction takes priority?

The rule written later inthe CSS wins, as longs as both selectors have the same specifications

How do you change the CSS for a page on a phone?

Put a media query like @media (max-width:330px) around the styles that would apply on smaller screens

Two things a website changes on mobile

The sidebar is pushed to the bottom and the nav does not have the hover available, as there is no visible mouse on a mobile device

Breakpoint Width

I chose 330px because its close to the width of the smallest phone. The mobile layout only turns on when the screen is super narrow.
