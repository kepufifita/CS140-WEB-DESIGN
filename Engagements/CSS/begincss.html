Inline, Embedded, and External CSS

Inline CSS is when you change the style in the html file within the same line of the code. Below me is an example of inline css

CSS<

Embedded CSS is when you change the style of things in a webpage within the style tags.

External CSS is when you create a CSS file for the style of your webpage and link it to your HTML file

Why use External CSS?

Separation of code. It keeps the code separate so that each expert for every aspect of the website can focus on their coding without being overwritten.

Another reason would be reusablility. We don't have to retype all of the html.

What is the selector?

The selector is within the CSS file. It helps you choose what things on the webpage will be changed.
